## Context

The four current pain points, grounded in code:

1. **Every query pays for full fusion**, even unambiguous ones. `fnd/tui/app.py:750-758` issues phrase + lex + syn sub-queries through `_filtered_raw_hits` for every keystroke. For an exact-keyword query that returns one obviously-correct match (e.g. a unique filename term), the phrase + syn passes are wasted Tantivy round-trips.

2. **No observability into ranking decisions.** When a result surprises the user, there's no way to inspect (a) which sub-queries ran, (b) per-sub-query BM25 scores, (c) RRF contributions, (d) why a regime fired. `fnd/fusion.py:243-253` already builds `_attribute_sources` and `_bm25_score_map` internally — the data exists but is discarded.

3. **`intent:` line missing from the multi-line DSL.** `fnd/fusion.py:155-185::parse_multi_input` recognizes `lex:`, `phrase:`, `syn:` only — `intent:` is silently dropped. The master plan §22 reserves an LLM cross-encoder slot for v2; the intent line should be in place when that lands.

4. **Preview pane freezes on large files.** `fnd/tui/app.py:825::_render_full_doc` calls `Searcher.get_file_chunks(parent_id)` synchronously on the event loop (`fnd/query.py:317-351`), which decodes every chunk's `body_struct` via `fnd.struct.decode` (one JSON parse per chunk). A 500-page book → 500 decodes → multi-second UI freeze when arrowing through results.

**Cohesion model.** Strong-signal bypass (this plan §1) and cascade widening (existing) are dual sides of the same dial. Together with intent gating, the layered search expresses three regimes through one decision function:

```
intent provided?              → never bypass (intent always means "disambiguate")
strong literal signal         → strong-signal-bypass    (single literal pass; fastest)
normal                        → fusion (phrase+lex+syn) (default)
sparse fusion (< limit/4)     → cascade (+fuzzy +syn)   (widest)
```

The trace records *which* regime fired and *why*. The `intent:` line is the single ungated cohesion lever — it disables strong-signal bypass, biases snippet selection, and is recorded on the trace for forward-compat with the §22 LLM reranker.

```python
# Strong-signal bypass thresholds. Operate on a normalized BM25 score
# ``s_norm = s / (1 + s)``, monotone in [0, 1) — query-independent and
# corpus-stable. Adapted from tobi/qmd (MIT) — see README acknowledgments.
STRONG_SIGNAL_MIN_NORM_SCORE: float = 0.85
STRONG_SIGNAL_MIN_NORM_GAP: float = 0.15


def normalize_bm25(score: float) -> float:
    """Map a raw BM25 score (positive, unbounded) into ``[0, 1)``.

    The transform ``s / (1 + s)`` is asymptotic to 1: it preserves
    ordering, compresses gaps at high values (so 30 vs 31 is barely
    distinguishable from 31 vs 32), and amplifies gaps at low values
    (so 1.5 vs 0.5 is meaningful). Matches the threshold semantics
    needed by strong-signal bypass.
    """
    if score <= 0.0:
        return 0.0
    return score / (1.0 + score)
```

```python
"""Regime-aware layered search (§9a + §9c + §9d).

One entry point — :func:`search_layered` — chosen by both the TUI and
the CLI. Encapsulates the three search regimes through a single
decision tree:

* **strong-signal** (§1, this plan): literal probe alone, when the
  normalized top BM25 ≥ 0.85 AND gap ≥ 0.15 AND no intent provided.
  Bypasses fusion's phrase + syn passes entirely.
* **fusion** (§9d): phrase + lex + syn sub-queries, RRF-fused. Default.
* **cascade** (§9c): widening fallback when fusion's chunk pool is
  sparse (< limit / 4). Adds fuzzy~1 and synonym passes.

The regime decision logic lives here, not scattered across modules.
The :class:`SearchTrace` returned when ``with_trace=True`` records
which regime fired and why.

Strong-signal bypass adapted from tobi/qmd (MIT) — see README.
"""

from __future__ import annotations

from typing import Literal, overload

from fnd.cascade import cascade_search
from fnd.explain import SearchTrace, StrongSignalTrace
from fnd.fusion import (
    STRONG_SIGNAL_MIN_NORM_GAP,
    STRONG_SIGNAL_MIN_NORM_SCORE,
    fusion_search,
    normalize_bm25,
)
from fnd.query import FileGroup, Hit, Searcher, group_by_file
from fnd.synonyms import SynonymTable


@overload
def search_layered(
    searcher: Searcher,
    *,
    query: str,
    limit: int,
    sections_per_file: int = 10,
    collection: str | None = None,
    synonyms: SynonymTable | None = None,
    metadata_filter: str | None = None,
    active_sources: list[str] | None = None,
    intent: str | None = None,
    profile: object | None = None,
    with_trace: Literal[False] = False,
) -> list[FileGroup]: ...


@overload
def search_layered(
    searcher: Searcher,
    *,
    query: str,
    limit: int,
    sections_per_file: int = 10,
    collection: str | None = None,
    synonyms: SynonymTable | None = None,
    metadata_filter: str | None = None,
    active_sources: list[str] | None = None,
    intent: str | None = None,
    profile: object | None = None,
    with_trace: Literal[True],
) -> tuple[list[FileGroup], SearchTrace]: ...


def search_layered(
    searcher: Searcher,
    *,
    query: str,
    limit: int,
    sections_per_file: int = 10,
    collection: str | None = None,
    synonyms: SynonymTable | None = None,
    metadata_filter: str | None = None,
    active_sources: list[str] | None = None,
    intent: str | None = None,
    profile: object | None = None,
    with_trace: bool = False,
) -> list[FileGroup] | tuple[list[FileGroup], SearchTrace]:
    if not query.strip():
        return ([], _empty_trace(query, intent)) if with_trace else []

    chunk_pool = limit * 10

    # Step 1: literal probe. Doubles as the bypass-decision input AND
    # (when bypass fires) the result set. When bypass does NOT fire,
    # fusion reuses this as its precomputed lex ranking — no wasted
    # Tantivy round-trip.
    probe = searcher._filtered_raw_hits(
        query,
        target=chunk_pool,
        collection=collection,
        metadata_filter=metadata_filter,
        active_sources=active_sources,
    )

    # Step 2: strong-signal check. Disabled when intent is supplied —
    # the obvious BM25 match may not be what the caller wants.
    ss_trace = _evaluate_strong_signal(probe, intent_present=bool(intent))
    if ss_trace.fired:
        hits = probe
        regime = "strong-signal"
        fusion_trace = None
        cascade_trace = None
    else:
        # Step 3: fusion (default).
        fusion_result = fusion_search(
            searcher,
            query=query,
            limit=chunk_pool,
            collection=collection,
            synonyms=synonyms,
            metadata_filter=metadata_filter,
            active_sources=active_sources,
            precomputed_lex_ranking=probe,
            with_trace=with_trace,  # forwarded; fusion returns tuple iff True
        )
        if with_trace:
            hits, fusion_trace = fusion_result  # type: ignore[misc]
        else:
            hits, fusion_trace = fusion_result, None  # type: ignore[assignment]

        # Step 4: cascade fallback when fusion is sparse.
        cascade_trace = None
        if len(hits) < max(1, limit // 4):
            cascade_result = cascade_search(
                searcher,
                query=query,
                threshold=chunk_pool,
                limit=chunk_pool,
                collection=collection,
                synonyms=synonyms,
                metadata_filter=metadata_filter,
                active_sources=active_sources,
                with_trace=with_trace,
            )
            if with_trace:
                cascade_hits, cascade_trace = cascade_result  # type: ignore[misc]
            else:
                cascade_hits, cascade_trace = cascade_result, None  # type: ignore[assignment]
            if len(cascade_hits) > len(hits):
                hits = cascade_hits
                regime = _cascade_regime_label(cascade_trace) if cascade_trace else "cascade"
            else:
                regime = "fusion"
        else:
            regime = "fusion"

    # Step 5: rerank + group. Identical for every regime.
    if profile is not None:
        from fnd.rerank import RankingProfile, rerank_hits

        assert isinstance(profile, RankingProfile)
        hits = rerank_hits(hits, profile=profile, query=query)

    groups = group_by_file(hits, limit=limit, sections_per_file=sections_per_file)

    if with_trace:
        trace = SearchTrace(
            query=query,
            intent=intent,
            regime=regime,
            strong_signal=ss_trace,
            fusion=fusion_trace,
            cascade=cascade_trace,
            elapsed_ms=0,  # populated by caller via timer; left 0 here for unit tests
        )
        return groups, trace
    return groups


def _evaluate_strong_signal(
    probe: list[Hit], *, intent_present: bool
) -> StrongSignalTrace:
    if intent_present or len(probe) < 2:
        top_n = normalize_bm25(probe[0].score) if probe else 0.0
        second_n = normalize_bm25(probe[1].score) if len(probe) > 1 else 0.0
        return StrongSignalTrace(
            top_score_norm=top_n,
            second_score_norm=second_n,
            gap_norm=top_n - second_n,
            threshold_score=STRONG_SIGNAL_MIN_NORM_SCORE,
            threshold_gap=STRONG_SIGNAL_MIN_NORM_GAP,
            fired=False,
            disabled_by_intent=intent_present,
        )
    top_n = normalize_bm25(probe[0].score)
    second_n = normalize_bm25(probe[1].score)
    gap = top_n - second_n
    fired = top_n >= STRONG_SIGNAL_MIN_NORM_SCORE and gap >= STRONG_SIGNAL_MIN_NORM_GAP
    return StrongSignalTrace(
        top_score_norm=top_n,
        second_score_norm=second_n,
        gap_norm=gap,
        threshold_score=STRONG_SIGNAL_MIN_NORM_SCORE,
        threshold_gap=STRONG_SIGNAL_MIN_NORM_GAP,
        fired=fired,
        disabled_by_intent=False,
    )


def _cascade_regime_label(trace: object) -> str:
    """Format the cascade regime as ``cascade(+fuzzy)`` / ``cascade(+syn)``
    / ``cascade(+fuzzy+syn)`` based on which passes ran."""
    from fnd.explain import CascadeTrace

    assert isinstance(trace, CascadeTrace)
    suffixes: list[str] = []
    for p in trace.passes:
        if p.name == "fuzzy" and p.new_count > 0:
            suffixes.append("+fuzzy")
        elif p.name == "synonym" and p.new_count > 0:
            suffixes.append("+syn")
    return f"cascade({''.join(suffixes)})" if suffixes else "cascade"


def _empty_trace(query: str, intent: str | None) -> SearchTrace:
    return SearchTrace(
        query=query,
        intent=intent,
        regime="empty",
        strong_signal=StrongSignalTrace(
            top_score_norm=0.0,
            second_score_norm=0.0,
            gap_norm=0.0,
            threshold_score=STRONG_SIGNAL_MIN_NORM_SCORE,
            threshold_gap=STRONG_SIGNAL_MIN_NORM_GAP,
            fired=False,
            disabled_by_intent=False,
        ),
        fusion=None,
        cascade=None,
        elapsed_ms=0,
    )
```

```python
"""Trace data structures for the ``--explain`` CLI flag and ``:explain``
TUI overlay.

Off the hot path: trace objects are only built when ``with_trace=True``
flows through :func:`fnd.layered.search_layered`. The data inside is
the same data that would otherwise be discarded after fusion / cascade
ran — no extra computation, just retention of internal state."""

from __future__ import annotations

from dataclasses import dataclass, field


@dataclass(slots=True, frozen=True)
class StrongSignalTrace:
    top_score_norm: float
    second_score_norm: float
    gap_norm: float
    threshold_score: float
    threshold_gap: float
    fired: bool
    disabled_by_intent: bool


@dataclass(slots=True, frozen=True)
class SubQueryTrace:
    source: str           # "phrase" | "lex" | "syn" | "fuzzy"
    query: str
    weight: float
    hit_count: int
    bm25_top: float       # raw BM25 of top hit in this sub-ranking (0.0 if empty)
    bm25_second: float
    rrf_k: int


@dataclass(slots=True, frozen=True)
class HitContribution:
    parent_id: str
    chunk_seq: int
    bm25_per_source: dict[str, float]   # raw BM25 keyed by source name
    rank_per_source: dict[str, int]     # 1-indexed rank in each sub-query; 0 = absent
    rrf_per_source: dict[str, float]    # weight / (k + rank) + position bonus
    fused_total: float                  # sum of rrf_per_source
    primary_source: str
    final_score: float                  # the BM25 score restored to Hit.score


@dataclass(slots=True, frozen=True)
class FusionTrace:
    query: str
    subqueries: list[SubQueryTrace]
    contributions: list[HitContribution]   # ordered as fusion returned them
    rrf_k: int
    pos_bonus_rank_1: float
    pos_bonus_rank_2_3: float
    default_weights: dict[str, float] = field(default_factory=dict)


@dataclass(slots=True, frozen=True)
class CascadePassTrace:
    pass_index: int       # 0=literal, 1=fuzzy, 2=synonym
    name: str             # "literal" | "fuzzy" | "synonym"
    query: str            # the actual query string issued
    hit_count: int        # hits this pass returned
    new_count: int        # hits added after dedup against earlier passes
    bm25_top: float


@dataclass(slots=True, frozen=True)
class CascadeTrace:
    query: str
    passes: list[CascadePassTrace]
    threshold: int
    final_count: int


@dataclass(slots=True, frozen=True)
class SearchTrace:
    query: str
    intent: str | None
    regime: str
    strong_signal: StrongSignalTrace
    fusion: FusionTrace | None
    cascade: CascadeTrace | None
    elapsed_ms: int

    def to_json(self) -> dict[str, object]:
        return {
            "query": self.query,
            "intent": self.intent,
            "regime": self.regime,
            "strong_signal": _strong_signal_to_json(self.strong_signal),
            "fusion": _fusion_to_json(self.fusion) if self.fusion else None,
            "cascade": _cascade_to_json(self.cascade) if self.cascade else None,
            "elapsed_ms": self.elapsed_ms,
        }


def _strong_signal_to_json(t: StrongSignalTrace) -> dict[str, object]:
    return {
        "top_score_norm": round(t.top_score_norm, 4),
        "second_score_norm": round(t.second_score_norm, 4),
        "gap_norm": round(t.gap_norm, 4),
        "threshold_score": t.threshold_score,
        "threshold_gap": t.threshold_gap,
        "fired": t.fired,
        "disabled_by_intent": t.disabled_by_intent,
    }


def _fusion_to_json(t: FusionTrace) -> dict[str, object]:
    return {
        "query": t.query,
        "rrf_k": t.rrf_k,
        "pos_bonuses": {"rank_1": t.pos_bonus_rank_1, "rank_2_3": t.pos_bonus_rank_2_3},
        "default_weights": t.default_weights,
        "subqueries": [
            {
                "source": s.source,
                "query": s.query,
                "weight": s.weight,
                "hit_count": s.hit_count,
                "bm25_top": round(s.bm25_top, 4),
                "bm25_second": round(s.bm25_second, 4),
```

```python
    subs: list[SubQuery],
    rankings: list[list[Hit]],
    primary_source: dict[tuple[str, int], str],
    bm25_scores: dict[tuple[str, int], float],

    sub_traces = [
        SubQueryTrace(
            source=s.source, query=s.query, weight=s.weight,
            hit_count=len(r),
            bm25_top=r[0].score if r else 0.0,
            bm25_second=r[1].score if len(r) > 1 else 0.0,
            rrf_k=_RRF_K_DEFAULT,
        )
        for s, r in zip(subs, rankings, strict=True)

    # rank/bm25/rrf for each (parent_id, chunk_seq) appearing in `out`.
    out_keys = {(h.parent_id, h.chunk_seq) for h in out}
    contributions: dict[tuple[str, int], dict[str, dict[str, float]]] = {
        k: {"rank": {}, "bm25": {}, "rrf": {}} for k in out_keys
```

```python
@dataclass(slots=True, frozen=True)
class MultiInput:
    """Parsed :multi block: typed sub-queries + optional intent line.

    intent does not produce a sub-query — see UXP-4 §3. It influences:
      * regime triage (intent disables strong-signal bypass)
      * snippet selection (chunks containing intent tokens preferred)
      * forward-compat with the §22 LLM cross-encoder (not yet wired)
    """
    subqueries: list[SubQuery]
    intent: str | None = None


def parse_multi_input(text: str, *, synonyms: SynonymTable | None) -> MultiInput:
    subs: list[SubQuery] = []
    intent: str | None = None
    for raw_line in text.splitlines():
        line = raw_line.strip()
        if not line or line.startswith("#"):
            continue
        if ":" not in line:
            continue
        prefix, value = line.split(":", 1)
        prefix = prefix.strip().lower()
        value = value.strip()
        if not value:
            continue
        if prefix == "intent":
            # Last-write-wins for intent (matches QMD's "at most one intent line").
            intent = value
            continue
        if prefix not in _DEFAULT_WEIGHTS:
            continue
        if prefix == "phrase" and not (value.startswith('"') and value.endswith('"')):
            value = f'"{value}"'
        elif prefix == "syn" and synonyms is not None and synonyms.groups:
            value = expand(value, synonyms)
        subs.append(SubQuery(query=value, weight=_DEFAULT_WEIGHTS[prefix], source=prefix))
    return MultiInput(subqueries=subs, intent=intent)
```

```python
def _make_snippet(body_text: str, query: str, *, ctx: int = _SNIPPET_CTX,
                   intent: str | None = None) -> str:
    """Return a short snippet centered on the first query-term match.

    When ``intent`` is supplied, prefers a window centered on a query-term
    occurrence whose context overlaps with intent tokens. Falls back to
    the first occurrence when no intent-aware candidate is found."""
    if not body_text:
        return ""
    lower = body_text.lower()
    needle = ""
    for term in query.lower().split():
        if term in lower:
            needle = term
            break
    if not needle:
        return body_text[:ctx].strip()

    # Find all occurrences of the needle.
    positions: list[int] = []
    start = 0
    while True:
        i = lower.find(needle, start)
        if i < 0:
            break
        positions.append(i)
        start = i + len(needle)

    if not positions:
        return body_text[:ctx].strip()

    chosen = positions[0]
    if intent:
        intent_tokens = [t.lower() for t in intent.split() if len(t) >= 3]
        if intent_tokens:
            for pos in positions:
                lo = max(0, pos - ctx // 2)
                hi = min(len(body_text), pos + ctx // 2)
                window = lower[lo:hi]
                if any(tok in window for tok in intent_tokens):
                    chosen = pos
                    break

    lo = max(0, chosen - ctx // 2)
    hi = min(len(body_text), chosen + ctx // 2)
    return body_text[lo:hi].replace("\n", " ").strip()
```

```python
@app.command()
def search(
    query: str,
    limit: int = 10,
    collection: str | None = typer.Option(None, "--collection", "-c"),
    meta: str | None = typer.Option(None, "--meta", help="Inline metadata-filter DSL (md hits only)."),
    explain: int | None = typer.Option(
        None, "--explain",
        help="Print JSON trace for the Nth hit (1-indexed). Routes through the regime-aware layered search.",
    ),
) -> None:
    """Search the index and print ranked file:locator snippets to stdout.

    With ``--explain N``, additionally emits a JSON trace for hit N
    showing which regime fired (strong-signal / fusion / cascade), the
    sub-queries that ran, per-hit BM25 contributions, and RRF math."""
    import json
    from fnd.config import load
    from fnd.filter_dsl import FilterError
    from fnd.layered import search_layered
    from fnd.migrate import prompt_and_rebuild_or_exit
    from fnd.query import Searcher

    prompt_and_rebuild_or_exit(index_dir=default_index_dir(), config=load())
    searcher = Searcher(index_dir=default_index_dir())
    try:
        if explain is None:
            hits = searcher.search(query, limit=limit, collection=collection, metadata_filter=meta)
            for hit in hits:
                _print_hit(hit)
            return
        groups, trace = search_layered(
            searcher,
            query=query,
            limit=limit,
            sections_per_file=5,
            collection=collection,
            metadata_filter=meta,
            with_trace=True,
        )
        # Flatten groups → hits in the same display order as the existing CLI.
        hits = [h for g in groups for h in g.hits]
        for hit in hits[:limit]:
            _print_hit(hit)
        if 1 <= explain <= len(hits):
            payload = trace.to_json()
            payload["explained_hit"] = {
                "index": explain,
                "parent_id": hits[explain - 1].parent_id,
                "chunk_seq": hits[explain - 1].chunk_seq,
                "score": round(hits[explain - 1].score, 4),
            }
            typer.echo(json.dumps(payload, indent=2))
        else:
            typer.echo(f"--explain {explain}: out of range (have {len(hits)} hits)", err=True)
            raise typer.Exit(code=1)
    except FilterError as e:
        typer.echo(f"invalid filter: {e.message} (col {e.column})", err=True)
        raise typer.Exit(code=1) from e


def _print_hit(hit) -> None:
    loc = ""
    if hit.page:

    elif hit.slide:
        loc = f":s.{hit.slide}"
    elif hit.heading_path:
        loc = f" §{hit.heading_path}"
    typer.echo(f"{hit.score:6.3f}  {hit.path}{loc}\n        {hit.snippet}")
```

```python
def _render_full_doc(self, parent_id: str, *, focus_chunk_seq: int) -> None:
    if self._searcher is None:
        return
    chunks = self._chunk_cache.get(parent_id)
    if chunks is not None:
        # Cache hit — same fast path as before.
        if parent_id != self._preview_parent_id:
            self._mount_chunks_for_file(parent_id, chunks)
            self._preview_parent_id = parent_id
            self._preview_load_progress = None
            self._refresh_status()
            self._refresh_match_scrollbar(chunks)
        self._scroll_preview_to_chunk(focus_chunk_seq)
        return

    # Cache miss — dispatch a worker that decodes off-thread, then
    # call_from_thread back to mount in batches. Keep the old preview
    # visible until mount begins. exclusive=True cancels any in-flight
    # load when the user moves to a different file.
    target_parent_id = parent_id
    target_focus = focus_chunk_seq
    searcher = self._searcher
    app = self

    def _load() -> None:
        try:
            chunks = searcher.get_file_chunks(target_parent_id)
        except Exception as e:
            app.call_from_thread(app.notify, f"Preview load failed: {e}", severity="error")
            return
        # Hand the chunks back to the event loop in one batch (mount
        # itself is then chunked via _mount_chunks_in_batches).
        app.call_from_thread(
            app._on_preview_chunks_loaded, target_parent_id, target_focus, chunks
        )

    self._preview_load_progress = (0, 1)  # placeholder while worker spins up
    self._refresh_status()
    self.run_worker(_load, thread=True, exclusive=True, group="preview-load")


def _on_preview_chunks_loaded(
    self, parent_id: str, focus_chunk_seq: int, chunks: list[FileChunk]
) -> None:
    """Worker callback (event-loop side). Updates cache, mounts in
    yielding batches, and updates the scrollbar match map."""
    self._chunk_cache[parent_id] = chunks
    if not chunks:
        self._preview_load_progress = None
        self._refresh_status()
        return
    # Mount in batches with explicit yields. Use create_task so we can
    # tick between batches; yielding via asyncio.sleep(0) lets the event
    # loop process key events mid-mount.
    import asyncio
    self._preview_parent_id = parent_id
    self._preview_load_progress = (0, len(chunks))
    self._refresh_status()
    self._refresh_match_scrollbar(chunks)

    async def _mount_batches() -> None:
        BATCH = 25
        pane = self.query_one("#preview_pane", VerticalScroll)
        for w in list(pane.children):
            w.remove()
        self._chunk_widgets = {}
        self._match_targets = {}
        first_chunk = chunks[0]
        title = Static(Path(first_chunk.path).name, classes="preview-title")
        pane.mount(title)
        is_markdown = first_chunk.kind == "md"
        for i, c in enumerate(chunks):
            if is_markdown:
                self._mount_markdown_chunk(pane, c)
            else:
                self._mount_plain_chunk(pane, c)
            if (i + 1) % BATCH == 0:
                self._preview_load_progress = (i + 1, len(chunks))
                self._refresh_status()
                await asyncio.sleep(0)
        self._preview_load_progress = None
        self._refresh_status()
        self._scroll_preview_to_chunk(focus_chunk_seq)

    asyncio.create_task(_mount_batches())
```
